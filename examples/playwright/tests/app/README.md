# App test cases

Tests **of the app under test** (TestHive) — the product's output: what a
DeviceDeck user generates to test *their own* app. Every spec here was
authored by an agent driving playwright-mcp; the assertions are about the
app's behaviour (a product lands in the cart, a wrong password is
rejected), never about DeviceDeck.

Generated by `../support/discover.mjs` (fresh-agent benchmark) and
`../support/generate.mjs`. Regenerate and run:

    DEVICEDECK_UDID=<udid> node tests/support/discover.mjs
    DEVICEDECK_UDID=<udid> npx playwright test app/

Tests **of DeviceDeck itself** — the mirror, settle barrier, scrolling,
ownership, video — live in `../platform/`, and must never be counted as
app test cases.
